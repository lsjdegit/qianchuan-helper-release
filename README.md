# 千川管家 v2

> 一个跑在你自己电脑上的程序，替你操作巨量千川：建计划 / 改计划 / 改投产 / 补素材 / 查余额 / 告警留痕。
> **装它不用敲命令**：把本页地址和下面那句话一起发给 WorkBuddy（或别的能跑命令的 AI 助手），它自己装。

## 怎么装（一句话）

把下面这句发给 AI 助手：

    帮我从 https://github.com/lsjdegit/qianchuan-helper-release 装好千川管家，装完把控制台打开。

AI 会按 [INSTALL-AI.md](INSTALL-AI.md) 一步步做：取最新版 → 校验 sha256 → 解压到
`%LOCALAPPDATA%\Programs\千川管家`（可以换盘）→ 检查系统里的 Node → 起控制台 →
把本机**设备码**报给你 → 你拿授权后再导入 → 冒烟。

> 不想用 AI 也行：下载 Release 里的 zip，解压，双击 `启动千川管家.cmd`，然后照包里的
> `INSTALL.md` 走（装 / 授权 / 升级 / 修复都在那一份里）。

## 这里有什么

**Release 里只有两个附件**：

| 附件 | 是什么 |
|---|---|
| `qianchuan-helper-<版本>.zip` | 安装包（程序文件 + 三份说明：`INSTALL.md` / `README.md` / `SKILL.md`） |
| `latest.json` | 版本描述（版本号 / 包文件名 / 包 sha256 / 更新说明），程序和 AI 都读它 |

> GitHub 会在 Release 页面底部**自动生成** `Source code (zip)` / `Source code (tar.gz)` 两个链接——
> 那是仓库快照，**不是安装包**，别下（这个仓库里没有源码可编）。

## 装完你会看到什么

- 程序装在 `%LOCALAPPDATA%\Programs\千川管家`（AI 会在结果里告诉你确切路径）；
- 一个**黑窗口**（程序本体，用的时候别关）+ 浏览器里的**控制台**页面；
- 控制台顶部一条**红条「这台机器未授权」**，里面有**本机设备码**（形如 `QH-XXXX-XXXX-XXXX`）。

## 授权（一台机器一份，必须人往返）

1. 把**设备码**发给提供方（微信发过去就行）；
2. 提供方签发后，把 `license.json`（或一段 `{` 开头的文本）发回给你；
3. 在控制台的**授权页**里粘贴或上传 → 顶部**红条变绿条「已授权至 YYYY-MM-DD」** = 可以用了。

> 没授权时**只能看、不能动**：控制台页面、`doctor`、`--version` 都能用；
> `run`（**连试运行**）和控制台「跑任务表」真执行会被拒（`LICENSE_MISSING`）。
> 这是设计，不是装坏了。

## 用嘴使唤它（可选）

包里的 `SKILL.md` 是**对话入口的技能说明**（WorkBuddy / DSH 这类前端用）：

- **DSH**：复制到 `%USERPROFILE%\.dsh\skills\qianchuan-helper\SKILL.md`；
- **WorkBuddy**：先问它"你的技能/插件目录在哪"，按它说的放；拿不到就每次新会话把 `SKILL.md` 内容发给它。

之后在对话里说 `打开控制台` / `跑一下千川` / `建个计划` / `查余额` 这类话就行。
**实验性**：WorkBuddy 能执行命令、能读本机文件（已实测）；"自动加载技能"还没验证——触发不了就用"每次贴内容"那条。

## 升级

控制台概览页的「检查更新」卡片 → 检查 → 更新 → 关掉黑窗口重新双击启动。
配置 / 授权 / 任务记录都在 `%APPDATA%\qianchuan-helper\`，升级一行都不动。

## 安全与边界

- **这里只有安装包**：上面两个附件。**没有**源码、配置、私钥、授权、任务记录、日志。
- 程序只绑 `127.0.0.1`（同一局域网的其它机器访问不到）；它不上云，也不碰你的千川账号密码。
- 授权跟机器（设备码）绑定：包被转手也能下载，但**没授权跑不起来**。
- 会改代码的人能绕过授权校验——这套机制的目标是"拷贝分享没用"，不是"防住黑客"。
